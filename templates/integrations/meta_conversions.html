Setup guide
1

Get your credentials

Open your dataset in Events Manager. Copy its ID and generate a Conversions API access token under Settings. Save both here.

2

Map and test

Map your funnel stages to events. Copy the Test Events code, then send an event using a real lead from the mapped pipeline. Check the event in Meta.

3

Start live delivery

Choose Live events, enable tracking and save. New leads and mapped stage changes are sent automatically. Existing leads are not backfilled.
