Documentation

Request Payload:

  • lead_id - id of the lead
  • name - name of the lead
  • phone - phone number of the lead
  • email - email address of the lead
  • notes - notes for the lead
  • stage - name of the stage
  • pipeline - name of the pipeline
  • event_type - create when a lead is created or update when a lead changes
  • custom_attributes - custom attributes of the lead

Sample Payload:

application/json 
{
  "lead_id": "2a196b3d-6e54-47be-88f7-f1ad02df827d",
  "name": "John Doe",
  "phone": "+919123456789",
  "email": "john.doe@example.com",
  "notes": "Interested in product X",
  "stage": "New leads",
  "pipeline": "Leads",
  "event_type": "create",
  "custom_attributes": {
    "company": "Example Pvt Ltd"
  }
}

Headers:

Verify that X-SHVYA-WEBHOOK-SECRET matches the secret configured above.

Each request also includes X-SHVYA-WEBHOOK-ID so your system can safely identify duplicate retry deliveries.

Expected Response:

Return any 2xx status code after successfully accepting the event. Requests time out after 10 seconds.

Retry Policy:

Failed requests are retried up to 2 times in the background:

  • First retry after 30 seconds
  • Second retry after 60 seconds
