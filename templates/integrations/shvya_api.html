Lead API documentation

Authenticate every API request with your Shvya API key.

X-SHVYA-API-KEY: <your-key>

Required fields

name · Lead name, max 150 characters
phone · Phone number, preferably with country code

Optional fields

email notes pipeline stage sequence attributes custom fields

Example request body

application/json 
{
  "name": "Aarav Sharma",
  "phone": "+919876543210",
  "email": "aarav@example.com",
  "notes": "Requested a product demo",
  "pipeline": "Sales",
  "stage": "New Leads",
  "sequence": "Demo Follow-up",
  "attributes": {
    "company": "Example Pvt Ltd",
    "city": "Delhi"
  }
}

200 OK

Lead added or updated successfully.

400 Bad Request

Validation or lead matching error.
