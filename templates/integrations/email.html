How to connect

The setup takes four steps. SHVYA tests authentication without sending an email.

1

Choose your provider

Select Gmail, Microsoft 365, Zoho or Custom SMTP. Known providers fill the standard server settings automatically.

2

Create an app password when required

For accounts protected by two-factor authentication, generate an app password in your email provider and use it here.

3

Confirm SMTP details

Check host, port, security and username. Your username is usually the full email address.

4

Test & connect

SHVYA authenticates to the SMTP server. A successful test activates this mailbox for automations and email events.

Gmail / Google Workspace

Use smtp.gmail.com, port 587 and STARTTLS. If 2-Step Verification is enabled, create a Google App Password and paste that password here.

Credentials stay server-side

Your password or app password is encrypted before storage and is never returned to the browser after saving.
