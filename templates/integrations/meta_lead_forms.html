Integration Guide Simple setup checklist
1
Create or open your Meta app

Open Meta Developers, choose the app connected to your Facebook Page, and add the Webhooks product if it is not already added.

Meta App Dashboard Meta Webhooks Docs
2
Add the webhook callback

In Meta Developers, open Webhooks, choose Page, paste this callback URL, use your verify token, then subscribe to leadgen.

{{ webhook_url }}
3
Get the Page access token

Open Graph API Explorer, select your Meta app, generate a token with page and lead permissions, then run this request for your Page:

PAGE_ID?fields=id,name,access_token

Copy the returned access_token. That is the Page access token. Paste it into Add Page or Edit Page here.

Graph API Explorer leads_retrieval Permission
4
Save the Page in Shvya

Use Add Page below. Enter Page name, Page ID, Page access token, and app secret if you want signature verification logs to match your app.

5
Find and map each form

Paste the Page token into Graph API Explorer, run this, then copy every form ID you want to connect:

PAGE_ID/leadgen_forms

Use Add Form below once per form. Different forms can go to different pipelines, stages, and field mappings.

Meta Lead Retrieval Docs
6
Subscribe the Page and test

In Graph API Explorer, set method to POST, keep the Page token pasted, and run:

PAGE_ID/subscribed_apps?subscribed_fields=leadgen

Then create a test lead in Meta's Lead Ads Testing Tool. Delete the old test lead first if Meta says one already exists.

Lead Ads Testing Tool Meta Lead Ads Docs
