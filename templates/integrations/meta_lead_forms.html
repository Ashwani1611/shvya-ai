Integration Guide Step by step
1. In Graph API Explorer

Select your app, generate a user token with page and lead permissions, then run:

772446079294595?fields=id,name,access_token

Copy the returned Page access token. In Graph API Explorer, a User Token can show errors for Page-only calls; paste the Page token into the token box when subscribing or listing forms.

2. Find forms

With the Page token pasted, run:

772446079294595/leadgen_forms

Copy each form's ID and save each one below with its own pipeline, stage, and mapping.

3. Subscribe the Page

Use POST with the Page token:

772446079294595/subscribed_apps?subscribed_fields=leadgen

A successful response is {"success": true}.

4. Test delivery
  • Open Meta Lead Ads Testing Tool.
  • Select Page, Product: Lead Retrieval, and the form.
  • Delete the old test lead, create a new one, then track status.
  • If Graph API says Page token required, paste the Page token again before submitting.
