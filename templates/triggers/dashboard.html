How Smart Triggers work

Choose when a rule runs, narrow it down with pipeline, stage, and attribute conditions, then pick one action. All attribute conditions must match; any selected value may match within a condition. Pipeline groups are alternatives.

Matching rules are evaluated in list order. A 30-second cooldown prevents the same rule from repeatedly acting on a lead. Admins manage rules; team members can view them.

Stage timers run once per stage entry. No-response timers start from the latest sent WhatsApp message and are cancelled by a reply. Background processing may add a short delay.
