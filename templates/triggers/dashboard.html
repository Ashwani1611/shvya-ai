How workflows work

Choose when a workflow runs, narrow it down with pipeline, stage, and attribute conditions, then pick one action. All attribute conditions must match; any selected value may match within a condition. Pipeline groups are alternatives.

Matching workflows are evaluated in list order. A 30-second cooldown prevents the same workflow from repeatedly acting on a lead. Admins manage workflows; team members can view them.

Stage timers run once per stage entry. No-response timers start from the latest sent WhatsApp message and are cancelled by a reply. Background processing may add a short delay.
