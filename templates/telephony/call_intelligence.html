What does call source mean?

Source is how the call was logged, separate from how the lead entered CRM.

  • Android APK · SIM: calls synced from the employee’s signed-in Android app.
  • CRM · Manual call: calls logged using Mark call in CRM. Manually creating a lead does not create a call.
  • Cloud · API events: call events submitted to the API by a configured integration. This option does not confirm a provider is connected.

New APK leads go to the signed-in employee’s pipeline. Calls to existing leads stay attached to that lead in its current pipeline.
