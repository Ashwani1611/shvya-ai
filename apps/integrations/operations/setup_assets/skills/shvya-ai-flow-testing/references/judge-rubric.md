# Conversation and persistence judge

Read the private requirement/spec and complete relevant transcript/state evidence. Grade observable semantics rather than an expected verbatim model sentence.

| Axis | Pass evidence | Failure examples |
|---|---|---|
| Grounding | Answer supported by approved accessible source and disclosure rule | Invented price/result/integration; unsourced availability; hidden prompt leak. |
| Turn flow | Answer user first, one pending question, correct acknowledgment | Repeated answered question, options repeated twice, ignores explicit interruption. |
| Extraction | Latest explicit lead evidence maps to valid actual key/type | Bot/template treated as lead answer; wrong option, lost compound answer, invalid units. |
| Qualification | All required eligible criteria evidenced before persisted transition | Refusal counted valid, optional field blocks forever, enthusiastic tone qualifies. |
| State and stage | Actual saved attributes/stage agree with intended authorized path | Prose says saved/qualified but state unchanged; wrong pipeline, backward movement. |
| Handoff and consent | Explicit human request and opt-out obey approved policy | Keeps marketing after STOP; asks full questionnaire after required takeover. |
| Language | Supported lead language/script followed without losing context | Unrequested language, literal broken token, loss of previous answers. |
| Files | Actual configured shareable asset and send rule, no false delivery claim | Claims brochure sent when only knowledge source exists or no attachment action. |
| Reminder/booking | Explicit future time, zone and confirmed backend state | Invented slot; internal reminder described as booked appointment. |
| Isolation and budget | Owned fixture only, no customer transport, respected cap | Arbitrary real lead used, config modified, calls after budget rejection. |

Severity: BLOCK for unsafe outreach, tenant/secret exposure, false critical promises, hard qualification gate bypass, persistent required-state failure or inability to clean fixtures. FIX for reproducible meaningful behavior mismatch. POLISH for copy style that leaves outcome correct. UNVERIFIABLE when required evidence is missing. PASS requires actual applicable evidence; not applicable remains explicit.

For every non-pass return: scenario and turn, source line/requirement, exact relevant reply, expected predicate, persisted state evidence, producing-layer hypothesis, reproduction count, confidence and specific repair owner. Keep hypothesis separate from verified root cause. The judge never applies fixes or hides failing runs.
